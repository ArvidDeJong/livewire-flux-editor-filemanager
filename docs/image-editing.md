# Image editing

## Inserting an image

Click the image button in the toolbar. Laravel Filemanager opens in a popup on the Images tab; upload or pick one or more images and confirm. Each image is inserted at the cursor, 400 pixels wide, with the class `tiptap-image`. Resize it from there.

If the popup is blocked, the browser shows the `messages.popup_blocked` text from the config.

## Single click: the resize menu

Click an image once and a small menu appears below it:

- The preset widths from `resize_presets`, by default 25%, 50%, 75% and 100%
- A field for a custom percentage, limited by `custom_width.min` and `custom_width.max`, applied with the button or Enter
- Align left, center and right

The menu updates the image's attributes in place, so alt text, title and any extra classes or styles you added survive. It closes when you click elsewhere.

## Double click: the edit modal

Double-click an image to open the modal with all its properties:

| Field | What it sets |
| --- | --- |
| Image | The URL, read-only. To use another image, delete this one and insert the new one |
| Alt text | The `alt` attribute. Screen readers and search engines use it; fill it in |
| Title | The `title` attribute, shown as a tooltip |
| Width | One of the presets, plus the current width if it isn't a preset |
| Alignment | None, left, center or right |
| Extra CSS classes | Classes added after the generated ones, for example `rounded-lg shadow` |
| Extra styles | Inline CSS added after the generated width and margins |

Enter in the title field saves, Escape or a click outside the modal cancels.

## The HTML

The editor writes standard `<img>` tags. A centered image at 50% with an extra class:

```html
<img
    src="/storage/photos/1/office.jpg"
    class="tiptap-image align-center rounded-lg"
    width="50%"
    style="width: 50%; margin-left: auto; margin-right: auto; display: block;"
    alt="Our office in Amsterdam"
    title="Head office"
    data-align="center"
>
```

Generated by the package, and rewritten on every change:

- Class `tiptap-image`, plus `align-left`, `align-center` or `align-right`
- The `width` attribute and a `width` style
- Margins for the alignment, and `display: block` for center
- `data-align`

Everything else in `class` and `style` is yours and is kept. Style `.tiptap-image` and the `align-*` classes in your front-end CSS to match your design; the package's stylesheet only styles the editor.

## Where the images come from

The image button inserts whatever URL Laravel Filemanager returns. With the default setup those are files under `public/storage`, served through the `storage:link` symlink. Uploads, folders, thumbnails and who may upload what are Laravel Filemanager's job; see its documentation for `config/lfm.php`.

Dropped and pasted images are different: they are embedded as base64 by default. See [Drag and drop](drag-and-drop.md).
